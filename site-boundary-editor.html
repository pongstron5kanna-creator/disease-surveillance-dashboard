วาดขอบเขตวัดและโรงเรียน บ้านดอนแท่น

แผนที่เดินดิน • ตำบลกลางเวียง อำเภอเวียงสา จังหวัดน่าน | กลับ Dashboard

1. เลือกสถานที่ที่จะวาด

กำลังโหลดแผนที่...
สีส้ม: วัดศรีดอนแท่น สีน้ำเงิน: โรงเรียน

เลือกสถานที่ก่อนวาด แล้วกดเครื่องมือ Polygon หรือ Rectangle ในแถบซ้ายของแผนที่ คลิกตามแนวรั้ว/ขอบที่ดินที่ตรวจสอบได้

2. แก้ไขและตรวจสอบ

ใช้เครื่องมือ Edit ขยับมุม, Drag ย้ายพื้นที่ หรือ Remove ลบพื้นที่ที่วาดผิด คุณสามารถเปลี่ยนสถานที่ในตัวเลือกเพื่อวาดอีกแห่งได้

ข้อมูลนี้เป็นแนวเขตจากการวาดเพื่อทำแผนที่ชุมชน ไม่ใช่เอกสารสิทธิ์หรือแนวเขตที่ได้รับการรับรองจากหน่วยงานราชการ

3. ส่งออกเพื่อใช้งานบน Dashboard

ระบบเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องนี้ชั่วคราว กรุณากดดาวน์โหลด GeoJSON เพื่อสำรองและส่งไฟล์กลับมาให้ผมนำขึ้น GitHub อย่างถาวร

ตำแหน่งอ้างอิงโรงเรียน: 18.5855923, 100.7463455 (ยังไม่ใช่ขอบเขตที่ดิน) ส่วนวัดจะให้คุณวาดตามตำแหน่งจริงที่เห็นในภาพ ไม่สมมติจุดอ้างอิง
