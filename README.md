# ระบบเฝ้าระวังโรคบ้านดอนแท่น — Village Surveillance Dashboard

พื้นที่: บ้านดอนแท่น ตำบลกลางเวียง อำเภอเวียงสา จังหวัดน่าน

[เปิดเว็บไซต์](https://pongstron5kanna-creator.github.io/disease-surveillance-dashboard/)

## แผนที่และชั้นข้อมูล (ปรับปรุง)

1. แผนที่ฐานเริ่มต้นเป็น **Esri World Imagery** พร้อมตัวเลือกสลับเป็น OpenStreetMap
2. **ขอบเขตบ้านดอนแท่น** ใช้ GeoJSON ที่ผู้ใช้วาดและยืนยันแล้ว โดยยังไม่ใช่แนวเขตทางราชการ
3. ปุ่ม **โหลดชั้นหลังคา/อาคาร** ดึงรอยเท้าอาคารจาก OpenStreetMap ผ่านบริการ Overpass หลายแห่ง; ถ้าระบบภายนอกมีปัญหายังใช้โหมดสำรวจได้
4. **แผนที่เดินดิน**:
   - **เพิ่มจุดบ้านจากสำรวจ** คลิกตำแหน่งบ้านที่สำรวจและยืนยันจากภาคสนาม
   - **วาดรูปอาคารจากสำรวจ** คลิกตามมุมรูปอาคารที่สำรวจจริง อย่างน้อย 3 จุด จากนั้นกด **จบรูปอาคาร**
   - กด **ส่งออก GeoJSON** เพื่อสำรอง/นำไปใช้ใน QGIS
   - กด **นำเข้าไฟล์สำรวจ** เพื่อคืนค่าจากไฟล์ที่เคยส่งออก
   - คลิกรายการสำรวจแล้วเลือก **ลบรายการนี้** หากปักผิด
5. ข้อมูลสำรวจที่เพิ่มในเบราว์เซอร์จะถูกเก็บไว้ใน **localStorage ของเบราว์เซอร์นั้นเท่านั้น** ไม่ส่งเข้า GitHub หรือฐานข้อมูลโดยอัตโนมัติ ควรส่งออกไฟล์ GeoJSON เป็นระยะ
6. ข้อมูลโรคทุกชุดยังเป็น **ข้อมูลสมมติ** สำหรับสาธิต

## ข้อจำกัดการนับจำนวนอาคาร/ครัวเรือน

- จำนวนอาคารจาก OSM อาจไม่ครอบคลุมบ้านทุกหลัง และอาคารหนึ่งหลังไม่เท่ากับครัวเรือนหนึ่งเสมอไป
- จำนวนบ้านที่ตรวจจากการเดินสำรวจเหมาะกับการทำทะเบียนอาคารเบื้องต้น แต่ควรตรวจซ้ำกับผู้นำชุมชนหรือ อสม.
- ห้ามนำข้อมูลผู้ป่วยระบุตัวตน พิกัดบ้านผู้ป่วย หรือข้อมูลสุขภาพส่วนบุคคลขึ้นเว็บไซต์สาธารณะ

## หมายเหตุเรื่องภาพดาวเทียม

Esri World Imagery เป็นภาพพื้นหลังที่อาจมีอายุแตกต่างกันในแต่ละพื้นที่ ข้อมูลไม่ได้เป็นภาพสด และไม่รับประกันว่าใหม่กว่า Google Maps; ควรตรวจข้อมูลภาพบริเวณบ้านดอนแท่นใน [Esri World Imagery Wayback](https://livingatlas.arcgis.com/wayback/)

ภาพของ Google Maps หรือผู้ให้บริการภาพอื่นอยู่ภายใต้เงื่อนไขลิขสิทธิ์/การใช้งาน ไม่ควรดึง tile โดยไม่ได้รับอนุญาต หรือคัดลอกรูปทรงอาคารจากภาพโดยอัตโนมัติ

## ชั้นอาคารจาก Overture Maps (เพิ่มใหม่)

Geojson.io เป็นเครื่องมือแก้ไข GeoJSON ไม่ได้แจกข้อมูลรอยเท้าอาคารโดยตัวเอง แนะนำให้ใช้ [Overture Maps Explorer](https://explore.overturemaps.org/) ซึ่งมีข้อมูลอาคารจากหลายแหล่ง แล้วทำดังนี้:

1. เปิด Explorer แล้วเลื่อนไปยังบ้านดอนแท่น (พิกัดอ้างอิง 18.58096,100.74879)
2. เปิดเฉพาะ **Buildings** และปิดชั้นอื่น จากนั้นใช้ **Download Visible** เพื่อดาวน์โหลด GeoJSON ที่ครอบคลุมขอบเขตหมู่บ้านทั้งหมด
3. ใน Dashboard กด **นำเข้า GeoJSON หลังคาอาคาร** เลือกไฟล์ที่ดาวน์โหลด
4. ระบบกรองรอยเท้าอาคารที่มีตำแหน่งเกี่ยวข้องกับขอบเขตหมู่บ้าน แสดงและนับรูปอาคาร จากนั้นกด **ส่งออกชั้นอาคาร** เพื่อสำรองข้อมูลที่กรองแล้ว
5. ข้อมูลอาคารที่นำเข้าจะพยายามเก็บไว้ใน localStorage ของเครื่อง/เบราว์เซอร์นั้น ๆ เท่านั้น ยังไม่แชร์ให้ผู้ใช้คนอื่นผ่าน GitHub โดยอัตโนมัติ

ข้อควรระวัง: Overture Maps และข้อมูลส่วนประกอบอาจมีข้อกำหนดสิทธิ์/การแสดงที่มาเฉพาะแหล่ง ต้องตรวจสอบก่อนเผยแพร่ไฟล์ที่นำเข้า และจำนวนอาคารไม่ใช่จำนวนครัวเรือนจริง

- GitHub Actions ดาวน์โหลดข้อมูลจริงจาก Overture Maps สำเร็จและเผยแพร่ที่ `data/don-thaen-buildings.geojson`
- จำนวนฟีเจอร์อาคารที่ตัดกับขอบเขตหมู่บ้าน: **835 รูปอาคาร**
- หน้าหลักจะโหลดชั้นอาคารนี้อัตโนมัติหลังโหลดขอบเขตหมู่บ้าน (ไม่ต้องกด Overpass)
- ข้อมูลเป็น **building footprints จากฐานข้อมูลเปิด** ไม่ใช่ผลยืนยันอาคารพักอาศัยจากการสำรวจและไม่ใช่จำนวนครัวเรือน
- โหมด **วาดหลังคาสี่เหลี่ยม (2 มุม)** ใช้สร้างรูปอาคารสาธิตจากตำแหน่งที่ผู้สำรวจตรวจสอบ โดยข้อมูลนี้เก็บในเบราว์เซอร์ และต้องกดส่งออก GeoJSON เพื่อสำรอง
- ห้ามนำภาพพื้นหลังถ่ายดาวเทียมไปคัดลอกหรือแจกจ่ายเป็นไฟล์ภาพโดยไม่ตรวจสิทธิ์จากเจ้าของ
