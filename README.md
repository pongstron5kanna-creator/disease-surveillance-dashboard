# ระบบเฝ้าระวังโรคบ้านดอนแท่น

Dashboard ต้นแบบ บ้านดอนแท่น ตำบลกลางเวียง อำเภอเวียงสา จังหวัดน่าน

## แผนที่
- **ขอบเขตหมู่บ้าน:** อยู่ใน `data/don-thaen-boundary.geojson` เป็นขอบเขตที่ผู้ใช้วาด ปรับความเรียบ และยืนยัน (ไม่ใช่เขตการปกครองอย่างเป็นทางการ)
- **แผนที่ฐาน:** แผนที่ถนนจาก OpenStreetMap และภาพดาวเทียม Esri World Imagery (สลับได้มุมขวาบนของแผนที่)
- **หลังคา/อาคาร:** กดปุ่ม “โหลดชั้นหลังคา/อาคาร” เพื่อดึงรูปอาคารจาก OpenStreetMap ผ่าน Overpass API แล้วนับอาคารที่ตัดกับขอบเขต
- เปิด/ปิดชั้นอาคาร ขอบเขต และหมุดอ้างอิงได้
- หากบริการ Overpass ไม่พร้อม โปรดลองใหม่ภายหลัง

## ข้อจำกัด
- **จำนวนอาคารบน OpenStreetMap ไม่ใช่จำนวนครัวเรือนหรือจำนวนหลังคาบ้านจริง** ข้อมูลอาจยังไม่ครบและมีสิ่งปลูกสร้างที่ไม่ใช่บ้าน
- การประมาณประชากรควรใช้ฐานข้อมูลครัวเรือนจากผู้ใหญ่บ้าน อสม. หรือทะเบียนที่ได้รับอนุญาตประกอบ
- **ข้อมูลโรคบน Dashboard เป็นข้อมูลสมมติเท่านั้น** ไม่ใช่รายงานโรคจริง
- อย่าใส่ข้อมูลผู้ป่วยหรือที่อยู่รายบุคคลใน Public Repository
