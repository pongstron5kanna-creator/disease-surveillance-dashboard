# ระบบเฝ้าระวังโรค บ้านดอนแท่น
ต้นแบบ Dashboard เฝ้าระวังโรคระดับหมู่บ้าน ตำบลกลางเวียง อำเภอเวียงสา จังหวัดน่าน

## เริ่มต้น
- เว็บไซต์อยู่ในไฟล์ `index.html` ซึ่งเปิดได้ด้วยเบราว์เซอร์
- แผนที่สร้างด้วย Leaflet และ OpenStreetMap ต้องใช้อินเทอร์เน็ต
- จุดอ้างอิงหมู่บ้าน 18.58096, 100.74879 ไม่ใช่ขอบเขตหมู่บ้านที่ได้รับรอง
- ตัวเลขผู้ป่วยทั้งหมดเป็น **ข้อมูลสมมติ** เพื่อการสาธิตเท่านั้น

## เผยแพร่ด้วย GitHub Pages
1. ไปที่ Settings > Pages
2. เลือก Deploy from a branch
3. Branch: main; Folder: /(root) แล้วกด Save
4. เมื่อเผยแพร่สำเร็จ เข้าเว็บไซต์ที่ https://pongstron5kanna-creator.github.io/disease-surveillance-dashboard/

## หลักความปลอดภัย
อย่าอัปโหลดชื่อ ที่อยู่ พิกัดบ้าน เบอร์โทร หรือข้อมูลสุขภาพรายบุคคลลงใน Public Repository หรือ GitHub Pages
ระบบนี้ยังไม่มีระบบรับรายงานจริง ฐานข้อมูล หรือระบบยืนยันตัวตน

## การพัฒนาในระยะถัดไป
ตรวจสอบขอบเขตหมู่บ้านจริง, สร้าง Data Dictionary, กำหนดนิยามผู้ป่วย, ระบบควบคุมสิทธิ์, และระบบสรุปข้อมูลแบบไม่เปิดเผยตัวตน
